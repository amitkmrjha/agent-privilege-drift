# Project documents

Records behind the experiment in this repository. The results themselves are in `../results/` (generated by `make analyse` and `make analyse-v2`); the registered design is in `../prereg/`.

| Path | What it is |
|---|---|
| `decisions/` | One short file per design decision (D01 to D33), with an index in `decisions/README.md`. |
| `deviations.md` | What changed after the design was frozen, and why. |
| `results/RESULTS.md` | Plain record of what was found (RQ1 to RQ3), exp-v1. |
| `results/results_exp_v2.md` | Results of the exp-v2 amendment (large model, no-mediator cells). |
| `pilot.md`, `power.md`, `data_summary.md` | Pilot findings, power analysis and data summary. These are tuning data, not results. |
| `SEQUENCE.md` | Sequence diagrams (Mermaid) of how a run executes. |
| `ollama_notes.md` | Notes on running the local model. |
| `research-reference/sources.md` | Availability and licence check of the benchmarks and baselines. |

**Terms.** "PRD" in these files means the project requirements document written before the build. It is not published here. Issue numbers such as `#26` refer to this repository's issue board.

**Run archive.** The run files are not in git. `exp_runs_final_2026-11-21.zip` (SHA-256 `90aaea8615ce3c65b8f7477ff4a569cdfd172071872bd1d2835aeab5ece5474f`) is the archive that `make analyse` reads; see the main README.

**Reading the results.** The primary test (H1) is a null result. Executed violations are zero under MAC and IBAC by construction (a violation is a call to an admin-tier tool, which both guards block), so that is a check that the gates work, not evidence that IBAC is better. On ToolPrivBench, IBAC and MAC make identical decisions (D26, D27).
